# Uptick Origin Testnet – v0.4.0 Upgrade Announcement

Dear Uptick Origin Validators,

We are excited to announce that the Uptick Origin testnet will be upgraded to v0.4.0:

- Target Block Height: 14607000
- Estimated Time: August 24th, 2026, at 10:00 UTC
- Commit Hash: f5ad33ee4b9468920ed74d2633f5bf8963ad6b45

## Changed

v0.4.0 is a major upgrade that replaces the core stack and adds full NFT interoperability:

- EVM engine migrated to `cosmos/evm` `x/vm` (go-ethereum v1.16): hardforks (Shanghai/Cancun/Prague) are activated by timestamp and EIP-7702 `SetCodeTx` is natively supported.
- IBC upgraded from ibc-go v8 to v10; the `capability` module and `ScopedKeeper` are removed.
- Cosmos SDK upgraded to v0.53 and `wasmd` to v0.61 (wasmvm v3).
- New `x/erc721` and `x/cw721` modules enable native Cosmos NFT <-> ERC721 / CW721 conversions and IBC transfers.
- ERC20 conversion is now provided by `cosmos/evm`'s `x/erc20` through the ERC20 IBC middleware.
- Legacy Ethermint `EthAccount`s and `ethsecp256k1` pubkeys are migrated to standard SDK account types automatically.
- The EVM chain-id is derived from genesis / `--chain-id` so JSON-RPC `eth_chainId` matches the EIP-155 id (1170).



## For Validators Running Cosmovisor

Please refer to our [Cosmovisor](https://upticknft.gitbook.io/uptick-network-documentation/guides/quickstart/cosmovisor) Setup Guide.

Please Note: Cosmovisor will perform a full backup unless you set the environment variable: UNSAFE_SKIP_BACKUP=true

```bash
# make a dir if you've not
mkdir -p $DAEMON_HOME/cosmovisor/upgrades/v0.4.0/bin

# Download the source code and build it
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git checkout v0.4.0
make build

# Copy binary files
cp ./build/uptickd $DAEMON_HOME/cosmovisor/upgrades/v0.4.0/bin/

# View version should be v0.4.0
$DAEMON_HOME/cosmovisor/upgrades/v0.4.0/bin/uptickd version --long
# commit: f5ad33ee4b9468920ed74d2633f5bf8963ad6b45
```

## For Validators NOT Using Cosmovisor

The chain will halt at the target block. Please manually update your binary as follows:

```bash
# Download the source code and build it
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git checkout v0.4.0
make install

# View version should be v0.4.0
uptickd version --long
# commit: f5ad33ee4b9468920ed74d2633f5bf8963ad6b45
```
