# Uptick Origin Testnet – v0.5.1 Upgrade Announcement

Dear Uptick Origin Validators,

We are excited to announce that the Uptick Origin testnet will be upgraded to v0.5.1:

- Target Block Height: 15,792,500
- Estimated Time: November 9th, 2026, at ~10:00 UTC
- Commit Hash: `dfd15f6ca19ac402e6a9ed66b02c197ca37325bb`
- Tag: `v0.5.1`

> **Important — verify your binary's commit hash.** An earlier `v0.5.1` release was published from the wrong commit (`81bf79e…`). Binaries built from it **cannot execute the v0.5.1 upgrade plan** and must be replaced. The correct binary reports `commit: dfd15f6ca19ac402e6a9ed66b02c197ca37325bb` — check with `uptickd version --long` before the upgrade height.

## Changed

State machine breaking:
- Adds the x/appmining store (uptick.appmining.v1) with the V1 model
  (EntitlementPool / Candidate / Challenge / Entitlement / Claim) and
  replays the v0.5.0 tail migrations for testnet convergence.
- Upgrade handler applies the V1 production baseline over InitGenesis
  defaults: denom fields follow the live staking bond denom (auptick on
  mainnet, auoc on the origin testnet), min-funded threshold, rule and
  assessment version allowlists, credential_required, and deposit-mode
  challenge access at values verified on the dev chain.

Security / dependencies:
- klauspost/compress bumped to v1.20.3 (GO-2026-6865).
- Toolchain bumped to go 1.26.10 (GO-2026-6809).

## For Validators Running Cosmovisor

Please refer to our [Cosmovisor](https://upticknft.gitbook.io/uptick-network-documentation/guides/quickstart/cosmovisor) Setup Guide.

Please Note: Cosmovisor will perform a full backup unless you set the environment variable: UNSAFE_SKIP_BACKUP=true

**Note the directory name is `v0.5.1`** — it must match the upgrade plan name exactly (same as the git tag `v0.5.1`):

```bash
# make a dir if you've not
mkdir -p $DAEMON_HOME/cosmovisor/upgrades/v0.5.1/bin

# Download the source code and build it
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git fetch --tags
git checkout v0.5.1
make build

# Copy binary files
cp ./build/uptickd $DAEMON_HOME/cosmovisor/upgrades/v0.5.1/bin/

# View version should be v0.5.1
$DAEMON_HOME/cosmovisor/upgrades/v0.5.1/bin/uptickd version --long
# commit: dfd15f6ca19ac402e6a9ed66b02c197ca37325bb
```

## For Validators NOT Using Cosmovisor

The chain will halt at the target block. Please manually update your binary as follows:

```bash
# Download the source code and build it
git clone https://github.com/UptickNetwork/uptick.git
cd uptick
git fetch --tags
git checkout v0.5.1
make install

# View version should be v0.5.1
uptickd version --long
# commit: dfd15f6ca19ac402e6a9ed66b02c197ca37325bb
```
